# secr-intel

**Doppel Social Engineering Intelligence Feeds**

Open threat intelligence from the Doppel SECR (Social Engineering Counter-intelligence and Research) team. Doppel's mission is to protect the world from social engineering attacks every day.

Each feed has its own folder, with its own README and data file. Feeds draw on Doppel telemetry and SECR research, plus public reporting from security vendors and researchers, credited by name in each record where identified.

| Feed | What it covers | Data file |
|---|---|---|
| [SSO Vishing](sso-vishing/) | Domains and domain patterns used in passkey and single-sign-on (SSO) enrollment voice-phishing (vishing) campaigns | [doppel-sso-vishing.csv](sso-vishing/doppel-sso-vishing.csv) |

Permitted use is set out in [LICENSE](LICENSE).

To report a problem, a false positive, or a new sighting, see the feed's README or [SECURITY.md](SECURITY.md).
